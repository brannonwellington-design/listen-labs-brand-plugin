07

Data Visualization

Monochromatic by default. Two swappable palette modes share one token namespace.

Brand mode — default · categorical (practical cap 5, then neutral fallback)

Hue 229 held constant — only lightness varies

Brand sequential · 7 stops · 100 → 700

Brand diverging · vermillion ↔ blue · CVD-safe

Default to bar and line charts. 1px strokes on every element — axes, grids, lines, borders. Bars: 2px corner radius, 1px inline gap. Grid lines use content-disabled. Caps: 7 series soft, 8 hard, then roll up to Other. 5+ series require redundant encoding — line style plus marker shape, never color alone. Contrast: 3:1 minimum for graphics, 4.5:1 for labels. Never red/green for diverging data. Global mode swaps to Okabe-Ito / Viridis / RdBu via data-dataviz-palette="global". One dominant data story per chart.

08

Never

If it's on this list, it doesn't ship.

Drop shadows or heavy depth effects
Rounded, bubbly UI
Bright/saturated accent colors beyond #0021CC
Bold or light font weights
Letter-spacing overrides
Cluttered layouts
Generic or decorative imagery
Odd numbers for spacing or sizing
Arbitrary border radius values outside the scale
Multiple competing focal points
Decorative elements that don't carry meaning
Emotion tokens on non-emotion data
