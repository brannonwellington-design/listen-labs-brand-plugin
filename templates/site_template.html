Data Visualization

Monochromatic by default. Two swappable palette modes share one token namespace.

Brand mode — default · categorical (practical cap 5, then neutral fallback)

{{STRIP_CATEGORICAL}}

Hue 229 held constant — only lightness varies

Brand sequential · 7 stops · 100 → 700

{{STRIP_SEQUENTIAL}}

Brand diverging · vermillion ↔ blue · CVD-safe

{{STRIP_DIVERGING}}

Default to bar and line charts. 1px strokes on every element — axes, grids, lines, borders. Bars: 2px corner radius, 1px inline gap. Grid lines use content-disabled. Caps: {{CAP_SOFT}} series soft, {{CAP_HARD}} hard, then roll up to Other. 5+ series require redundant encoding — line style plus marker shape, never color alone. Contrast: 3:1 minimum for graphics, 4.5:1 for labels. Never red/green for diverging data. Global mode swaps to Okabe-Ito / Viridis / RdBu via data-dataviz-palette="global". One dominant data story per chart.
